# Implementasi Metode Gauss-Seidel

## 📌 Deskripsi
Project ini merupakan implementasi metode Gauss-Seidel menggunakan bahasa pemrograman Python untuk menyelesaikan Sistem Persamaan Linear (SPL).

Metode Gauss-Seidel merupakan metode iteratif yang menghitung nilai setiap variabel secara berurutan menggunakan nilai terbaru dari hasil perhitungan sebelumnya.

## 🎯 Tujuan
Tujuan dari proyek ini adalah:
- Memahami konsep metode Gauss-Seidel.
- Menyelesaikan Sistem Persamaan Linear (SPL).
- Mengimplementasikan algoritma numerik ke dalam bentuk program Python.
